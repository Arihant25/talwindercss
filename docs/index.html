Install

The simplest way is a single link tag. It gives you every class in the framework.

<link rel="stylesheet" href="https://arihant25.github.io/talwindercss/dist/talwinder.css">

If you'd rather host it yourself, drop talwinder.css into your project and reference it.

<link rel="stylesheet" href="/css/talwinder.css">

Fonts are loaded from Google Fonts when the framework is used through the CDN. If you host it yourself and want the display faces, add this in your <head>:

<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Yatra+One&family=Noto+Serif:wght@400;700&family=Kalam&display=swap" rel="stylesheet">

Philosophy

TalwinderCSS is built on three ideas.

  1. Utility classes plus a few components. Spacing, colour, and layout classes work the way you expect from any utility framework. On top of that, there are named components (tw-chai-cup, tw-ticket) for shapes that would be tedious to compose from scratch.
  2. Named colours instead of hex codes. A colour like sindoor is easier to remember and easier to explain to a teammate. Designers and developers share a vocabulary.
  3. No build step. One CSS file. No PostCSS, no compiler, no config. The framework fits in a static asset folder.

TalwinderCSS is opinionated about colour, borders, and shadows. If those opinions clash with your project, override the CSS variables at the top of talwinder.css and every class picks up the change.

Raat (dark) mode

Set data-tw-theme="raat" on <html>, <body>, or any container. The palette shifts to a warm dark background with kerosene-lamp yellows as accents.

<html data-tw-theme="raat">

To follow the system preference, toggle the attribute in JavaScript based on matchMedia("(prefers-color-scheme: dark)").

Typography

Three font families, chosen so that a page looks distinct without needing custom CSS.

  • tw-font-display: Yatra One, a rounded display face with weight to it. Used for headings.
  • tw-font-body: Noto Serif for running text.
  • tw-font-hand: Kalam, a Devanagari-friendly handwriting face. Good for quotes and callouts.
  • tw-font-mono: JetBrains Mono for code.

Sizes follow a familiar scale: tw-text-xs through tw-text-7xl. Weights: tw-font-light, tw-font-normal, tw-font-bold, tw-font-black.

Spacing

The spacing scale is close to a 4-pixel grid: 1 is 4px, 2 is 8px, and so on up to 24 (96px). Apply as padding (tw-p-4, tw-px-6, tw-py-8) or margin (tw-m-0, tw-mt-4, tw-mx-auto).

Container

A centred container with a max width. Three sizes.

  • tw-container: 1200px max, the default.
  • tw-container-sm: 720px, for reading.
  • tw-container-lg: 1400px, for dashboards.

Flex & grid

Familiar helpers: tw-flex, tw-flex-col, tw-items-center, tw-justify-between, tw-gap-4, tw-grid, tw-grid-cols-3, tw-col-span-2. On screens narrower than 768px, multi-column grids collapse to a single column automatically.

Buttons

The base tw-btn is a marigold rectangle with a hard black border and a chunky offset shadow. Colour variants change the fill: tw-btn-sindoor, tw-btn-mehndi, tw-btn-peacock, tw-btn-jamun, tw-btn-brass. Sizes: tw-btn-sm, tw-btn-lg. Full-width: tw-btn-block. A ghost variant, tw-btn-ghost, has a transparent fill.

Accessibility notes

  • All text colours in the palette meet WCAG AA on the recommended background pairs (sindoor on cream, marigold on charcoal, and so on).
  • All animations respect prefers-reduced-motion.
  • The hoarding pauses on hover so users can read the ticker.
  • Buttons keep a visible focus ring through the browser default; you can override with a custom rule if you need brand-specific focus.
