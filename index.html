TalwinderCSS भारतीय कला, सीएसएस में

Nine art traditions, from Kutch block print to Thanjavur gold leaf, each one an attribute you set on <html>. Change it and the palette, ornaments, border weights and display face all move together. The markup never changes.

Ornaments are masks, not pictures

Every motif is stored once as an SVG alpha mask. The framework paints --tw-orn-ink through it, so one asset serves all nine styles at any colour and any size. Nothing here is a raster image and nothing is fetched over the network.

Components that know where they came from

A thali is a circle with bowls around the rim. A jharokha is a balcony under an ogee arch. These shapes have no equivalent in a Western component library, so the framework supplies them.

How it is put together

One attribute, whole page

Art styles reassign semantic tokens. Components read only tokens. That indirection is why nine wildly different looks need no component-level overrides.

Styles nest

Set data-tw-art on any element, not just the root. A truck-art page can hold one chikankari section without a wrapper class or a cascade fight.

Scroll-driven, not timer-driven

The kolam rules above draw themselves using animation-timeline: view(), behind an @supports guard. No scroll listener, no observer, no JavaScript.

Indic scripts get room

Devanagari, Tamil and Bengali hang glyph parts above and below the line. The base stylesheet gives :lang() matches a taller line-height so matras are not clipped.

Sized honestly

40 KB minified, 9.5 KB over the wire, ornaments included. The motifs are inline SVG masks, so there is no sprite sheet and no second request.

Prefixed and quiet

Every class starts with tw- and every variable with --tw-. Drop it beside Bootstrap or Tailwind without a collision.

Nine styles. Same markup.
