Utility CSS for building
Indian-style websites.

One CSS file. Named colours (saffron, sindoor, mehndi), background patterns (bandhani, brocade, warli), and components (chai cup, ticket stub, classified ad) that you use as classes in your HTML. No JavaScript. No build step.

Why another framework?

There are frameworks for brutalism, glassmorphism, skeuomorphism. This one leans on visual vocabulary from India, which has been sitting there in plain sight the whole time.

🪔

Named colours you'll remember

Saffron, sindoor, mehndi, jamun, mor-pankh. No hex code guessing. The palette maps to physical objects most people have seen.

🧵

Patterns as backgrounds

Bandhani dots, rickshaw diagonals, Warli-style repeats, gold-brocade checks. All done in CSS. No image files, no build step.

🚛

Real components

Truck-art buttons, chai-cup containers, classified-ad cards, rangoli spinners. Copy the class, keep your markup.

📜

One file. No JavaScript.

Around 25 KB of CSS. Add one <link> and you're done. No PostCSS, no config, no toolchain, no opinions about your bundler.

🌙

Raat mode built in

Set data-tw-theme="raat" on any element. The palette shifts to a warm dark that keeps marigold and sindoor readable at night.

🤝

Plays nicely

Every class is prefixed with tw-. Drop it into an existing Tailwind, Bootstrap, or Bulma page without collisions.

A few components

Every one of these is one class on plain HTML. No wrappers, no config.

Rangoli card

Ornate corners without a single SVG. Just CSS pseudo-elements sitting on a bordered box.

<div class="tw-card-rangoli">
  <h3 class="tw-om">Namaste</h3>
  <p>Content goes here.</p>
</div>

Bandhani card

Repeating dot pattern on a sindoor red base. Prints well, scales at any size, weighs almost nothing.

<div class="tw-card-bandhani">
  <h3>Deep discount</h3>
  <p>Only today.</p>
</div>

Chai cup

Half kettle, half container. Use it for testimonials, quick tips, or that one sentence that needs a bit of warmth.

<div class="tw-chai-cup">
  <p>Ek cutting, please.</p>
</div>

The practical bits

Every named colour clears WCAG AA on its recommended background. The dark theme keeps sindoor and marigold at readable contrast instead of desaturating them. Motion respects prefers-reduced-motion. Nothing depends on JavaScript. The whole file is around 25 KB uncompressed and gzips to about 6 KB.
